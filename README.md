# Campus Laundry — UX Research & Information Architecture

A UX research case study exploring how students experience, understand, and navigate a campus laundry service.

## Project Overview

The project focuses on understanding student needs and identifying usability problems in the existing campus laundry experience.

The research process was used to develop a clearer Information Architecture and prioritize the features required for an improved campus laundry service.

## UX Research Process

The project followed this process:

1. Problem Statement
2. Proto Persona
3. Persona Validation
4. Observation Blog
5. Empathy Map
6. Journey Map
7. User Stories
8. Feature Identification
9. Card Sorting
10. Information Architecture V1
11. Tree Testing
12. Information Architecture V2
13. MoSCoW Prioritization
14. DFV Matrix
15. MVP Definition

## Key Research Activities

### User Research
- Developed a proto persona
- Conducted user interviews
- Validated the persona
- Documented observations
- Created an empathy map
- Created a user journey map

### Information Architecture
- Developed an initial Information Architecture
- Conducted card sorting
- Conducted tree testing
- Refined the Information Architecture into V2

### Feature Prioritization
- Identified and evaluated proposed features
- Used MoSCoW prioritization
- Evaluated features using a DFV matrix
- Defined the Minimum Viable Product

## Information Architecture

The refined Information Architecture organizes the campus laundry service around the student's tasks and decision-making process.

The V2 structure includes:

- Home
- Availability
- Services
- My Laundry
- Payments
- Help & Support
